# Trailhead

MVP landing page for builders who have a product but don’t know where — or how — to get their first customers.

## What’s on the page

- Product story: five questions → matched communities, ready posts, reply scripts, 14-day plan
- Beta signup for a **99-person** run
- Live scarcity copy: “Hurry — only X spots left” as people join (stored in the browser for this demo)

## Run locally

```bash
npm start
```

Open [http://localhost:4173](http://localhost:4173).
